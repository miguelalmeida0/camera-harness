# Gate 2A Claim Language Policy

Gate 2A copy must describe what the system can prove from local symbolic state. It must not imply autonomous perception, production readiness, or model/VLM intelligence.

## Allowed Phrases

- manual local confirmation;
- symbolic event;
- state-backed HUD;
- physical trace validated;
- privacy/model checks passed;
- local camera preview;
- no raw media persisted;
- zero LLM/VLM calls.

## Forbidden Phrases

- autonomous vision;
- automatically understands your desk;
- production ready;
- portfolio ready;
- cinematic demo ready;
- detects everything;
- AI vision proven;
- gesture recognition solved;
- VLM-powered;
- cloud vision.

## Replacement Rule

When copy is tempted to claim perception, replace it with the backing state:

- use `operator confirmed phone moved` instead of `phone detected`;
- use `symbolic event emitted` instead of `AI understood action`;
- use `physical trace validated` instead of `demo ready`;
- use `zero LLM/VLM calls` instead of `local AI`.

## Failure Rule

Any forbidden phrase in Gate 2A UI, docs, fixtures, reports, or bug reports blocks approval until removed or explicitly quarantined as a negative test fixture.
