# Suggestion UX Claim Boundary

Suggestion UX must describe confirmation-bound local motion proxy behavior. It must not imply autonomous perception, object recognition, production perception, or auto-completion readiness.

## Allowed UX Language

- Camera suggestion
- Possible motion
- Requires confirmation
- Local motion proxy
- Symbolic evidence
- Accepted suggestion
- Rejected suggestion

## Forbidden UX Language

- Camera identified your action
- Camera understands your desk
- AI saw your hand
- Autonomous detection
- Object recognition
- Gesture recognition proven
- Auto-completion ready
- Production perception

## Display Rule

Every suggestion display must make confirmation visible. Success styling must distinguish accepted suggestions from automatic perception.

## Failure Rule

Any forbidden claim in UI, exported reports, trace metadata, docs, or bug reports blocks Gate 3B-Live unless it is isolated inside an adversarial/negative fixture.
