# Gate 1D No-Polish Boundary

Gate 1D is a usability recovery gate. It is not a polish gate.

## Allowed

- Making controls usable.
- Fixing button flow.
- Making calibration understandable.
- Making debug HUD readable.
- Making export clear.
- Making validation instructions clear.
- Showing privacy/model status plainly.
- Showing uncertainty plainly.
- Labeling manual local confirmation plainly.

## Forbidden

- Cinematic HUD.
- Visual effects.
- Portfolio styling.
- Fake progress animations.
- Hiding uncertainty.
- Hiding manual confirmation.
- Implying AI vision works when manual buttons are used.
- Claiming demo readiness.
- Claiming production readiness.
- Claiming autonomous visual recognition.
- Starting Gate 2.

## Boundary Test

The change is allowed if it helps the user complete the local ritual, export symbolic JSON, or understand validation.

The change is forbidden if it makes the app look more impressive without improving local operation, replayability, privacy visibility, or validation clarity.
