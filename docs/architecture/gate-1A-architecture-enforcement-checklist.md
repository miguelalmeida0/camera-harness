# Gate 1A Architecture Enforcement Checklist

Gate 1A is release-blocked until every mandatory check below passes for the live local perception adapter and any exported live trace. The source contracts are `docs/contracts/event-schema.v0.md`, `docs/contracts/replay-fixture-schema.v0.md`, `docs/architecture/gate-1A-schema-freeze.md`, and `docs/architecture/live-perception-adapter-boundary.md`.

| Check name | Why it matters | Pass condition | Fail condition | Owner | Validation command or method | Release-blocking severity |
| --- | --- | --- | --- | --- | --- | --- |
| `gate1a_event_schema_v0` | Prevents live perception from drifting away from the replay-tested event contract. | Every state-bearing live event validates against `event-schema.v0.md`. | Any live event uses v1 envelope fields, unknown type, missing field, invalid payload, or invalid evidence. | GAUNTLET | `node packages/evals/bin/darkquest-eval.mjs replay --repeat 3 <fixture>` plus event validator. | Critical |
| `gate1a_replay_fixture_schema_v0` | Keeps live traces replayable by the existing harness. | Exported trace is valid `darkquest.replay_fixture.v0`. | Unknown top-level fields, missing required sections, or incompatible schema value. | GAUNTLET | Replay fixture schema validation in `darkquest-eval`. | Critical |
| `gate1a_no_experimental_state_event` | Prevents experimental perception signals from becoming quest truth. | Experimental observations stay outside `input_events` and state-bearing streams. | Event has `experimental: true`, `ignored_by_state_machine: true`, or experimental payload in `input_events`. | PARALLAX, GAUNTLET | Runner failure code `experimental_state_event`; trace export scan. | Critical |
| `gate1a_evidence_raw_media_false` | Makes evidence references safe to persist and replay. | Every live evidence ref has `contains_raw_media: false` before export, or v0 evidence is proven symbolic by scanner. | Evidence is missing the false assertion in live adapter output or references raw media. | PARALLAX | Adapter unit tests and trace privacy scan. | Critical |
| `gate1a_no_raw_frame_bytes` | Raw frames expose private desk content and break symbolic replay. | No bytes, buffers, frame blobs, or `raw_frame:` refs appear in trace or fixture. | Any raw frame bytes or raw frame reference is written. | PARALLAX, GAUNTLET | Privacy scanner and failure code `raw_media_evidence`. | Critical |
| `gate1a_no_base64_images` | Base64 images smuggle raw media through JSON. | No `data:image/*`, `base64`, or image payload string exists. | Any base64 media string appears in payload, evidence, memory, or report. | GAUNTLET | Recursive JSON string scan. | Critical |
| `gate1a_no_screenshots` | Screenshots are raw visual captures and not replay-safe. | No `.png`, `.jpg`, `.jpeg`, `.webp`, screenshot key, or screenshot path appears. | A screenshot artifact is referenced or persisted. | PARALLAX, GAUNTLET | Trace recorder privacy scanner. | Critical |
| `gate1a_no_raw_audio` | Audio is outside the Focus Ritual replay contract and can leak private content. | `privacy.contains_audio == false` and no audio refs exist. | Audio flag true or `.wav`, `.mp3`, `raw_audio:`, `data:audio/*` appears. | GAUNTLET | Fixture privacy validation and recursive scan. | Critical |
| `gate1a_no_private_notebook_text` | Notebook content is private; the quest needs only symbolic writing evidence. | No OCR, notebook text, or transcribed private content appears. | Any `ocr`, `notebook_text`, visible writing text, or private note content is written. | PARALLAX, GAUNTLET | Trace export scanner and manual spot check for first live trace. | Critical |
| `gate1a_no_llm_calls` | Gate 1A proves local symbolic perception before agent/model assistance. | `llm_calls == 0`, `expected.model_calls == []`, no provider records. | Any LLM route or provider call appears. | AXIOM, GAUNTLET | Model-call checker in replay report. | Critical |
| `gate1a_no_vlm_calls` | VLM fallback would hide local perception failures and add privacy/cost risk. | `vlm_calls == 0`, no Tier 4 route, no visual provider call. | Any VLM route, Tier 4 escalation, or visual cloud call appears. | AXIOM, GAUNTLET | Model-call checker and failure code `unexpected_model_call`. | Critical |
| `gate1a_quest_reducer_pure` | Keeps state deterministic, replayable, and debuggable. | `reduceQuestState(previousState, stableEvent)` has no side effects and same input gives same output. | Reducer reads clocks, random, storage, network, camera, models, memory, or mutates inputs. | AXIOM | Purity tests in `docs/architecture/quest-engine-purity-tests.md`; code review. | Critical |
| `gate1a_live_trace_replays` | Visual demo safety depends on replayability, not inspection. | Live trace fixture passes `darkquest-eval replay --repeat 3`. | Fixture missing, invalid, failing, or nondeterministic. | GAUNTLET | `node packages/evals/bin/darkquest-eval.mjs replay --repeat 3 fixtures/replay/live/live_focus_ritual_001.v0.json` | Critical |
| `gate1a_valid_confidence` | Confidence gates prevent low-certainty progress. | Every confidence is a number `0.0 <= confidence <= 1.0`. | Missing, nonnumeric, below `0`, or above `1`. | PARALLAX, GAUNTLET | Runner failure code `invalid_confidence`. | Critical |
| `gate1a_monotonic_timestamps` | Replays require a deterministic sequence. | Input event `timestamp_ms` values are non-negative and monotonic non-decreasing. | Negative, non-integer, or out-of-order timestamp. | PARALLAX, GAUNTLET | Runner failure codes `invalid_timestamp`, `non_monotonic_timestamps`. | Critical |
| `gate1a_allowed_producers` | Prevents packages from impersonating other boundaries. | Producers are from the v0 allowlist and match package responsibility. | Unknown producer or live adapter emits downstream producer. | AXIOM, GAUNTLET | Runner failure code `invalid_event_producer` plus package-boundary review. | Critical |
| `gate1a_meaningful_payloads` | Payloads are the guard evidence; vague fields recreate false confidence. | Required payload fields exist and no `data`, `stuff`, `info`, `raw`, or `blob` keys carry state. | Missing guard field, vague payload key, or broad catch-all payload. | GAUNTLET | Runner failure code `payload_shape_mismatch`. | Critical |
| `gate1a_honest_uncertainty` | The HUD and replay must show blocked perception honestly. | Ambiguous or below-threshold live observations hold state or emit `scene.uncertain` / `confidence.changed`. | Adapter guesses progress, drops uncertainty, or HUD hides uncertainty. | PARALLAX, GAUNTLET | Replay failure code `hud_uncertainty_hidden`; adapter ambiguity tests. | Critical |
| `gate1a_scene_reset_on_bump` | Camera bump invalidates zones and prior geometry. | Camera bump/reset emits `scene.reset` or blocks zone-specific progress until reset/calibration. | Camera bump occurs with no reset/uncertainty and quest continues on stale zones. | PARALLAX | Local adapter test fixture; trace review for `scene.reset`. | Critical |

## Gate 1A Validation Commands

```sh
node packages/evals/bin/darkquest-eval.mjs replay --repeat 3 fixtures/replay/focus_ritual_happy_path.v0.json
node packages/evals/bin/darkquest-eval.mjs gate-0b fixtures/replay/gate_0b_manifest.json
node packages/evals/bin/darkquest-eval.mjs replay --repeat 3 fixtures/replay/live/live_focus_ritual_001.v0.json
```

Run the live trace command only after `fixtures/replay/live/live_focus_ritual_001.v0.json` exists. Missing live traces must not be silently treated as pass.
