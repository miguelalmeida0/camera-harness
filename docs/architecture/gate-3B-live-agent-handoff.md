# Gate 3B-Live Agent Handoff

Gate 3B-Live validates physical suggestion traces. It does not unlock Gate 3C.

## To Multimodal Perception & Interface Researcher

- Export physical suggestion traces.
- Keep accept/reject explicit.
- Preserve suggestion metadata.
- No auto-complete.
- No raw media.
- No model calls.
- Keep future-step suppression intact.
- Keep manual confirmation visible.

## To Harness, Evaluation, Memory & Safety Researcher

- Validate physical suggestion traces.
- Keep Gate 3C locked.
- Prepare precision measurement.
- Reject autonomous claims.
- Verify suggestion-only records cannot progress quest.
- Verify accepted suggestions include `human_correction` evidence.
- Verify metadata keeps `auto_completed_steps`, `llm_calls`, `vlm_calls`, and `raw_media_persistence` at `0`.

## Handoff Rule

Gate 3B-Live proves replayability and measurement readiness for confirmation-bound suggestions. It does not prove autonomous vision or approve auto-completion.
