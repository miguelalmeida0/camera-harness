# Gate 3B-Live Claim Language Policy

Gate 3B-Live language must describe physical suggestion traces and confirmation-bound symbolic evidence. It must not imply autonomous perception, object detection, production perception, or auto-completion readiness.

## Allowed Phrases

- physical suggestion trace;
- camera suggestion;
- motion proxy;
- accepted suggestion;
- rejected suggestion;
- symbolic evidence;
- requires confirmation;
- no raw media;
- zero model calls.

## Forbidden Phrases

- camera identifies my actions automatically;
- autonomous desk understanding;
- action recognition solved;
- object detection proven;
- production perception;
- auto-complete ready;
- VLM/cloud vision.

## Replacement Rule

- Use `physical suggestion trace` instead of `vision proof`.
- Use `accepted suggestion` instead of `automatically detected action`.
- Use `requires confirmation` instead of `completed by camera`.
- Use `zero model calls` instead of `AI vision`.

## Failure Rule

Forbidden phrases block Gate 3B-Live unless they appear only inside negative test fixtures or claim-scanner tests.
