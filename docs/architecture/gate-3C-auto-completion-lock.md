# Gate 3C Auto-Completion Lock

Gate 3C and confidence-based auto-completion remain blocked.

Gate 3C can only be discussed after:

- Gate 3B passes;
- Gate 3B-Live passes;
- at least 20 suggestion attempts are logged;
- accept/reject outcomes are available;
- false-positive rate is measured;
- false-negative observations are documented;
- suggestion precision/false-positive behavior is measured;
- accept/reject logs exist;
- uncertainty behavior is stable;
- a separate auto-completion eval exists;
- user explicitly approves moving beyond confirmation-based flow.

## Still Blocked

- blind auto-completion;
- quest completion from suggestion alone;
- object recognition claims;
- autonomous vision claims;
- production perception claims;
- model/VLM perception;
- future-step bypass;
- hidden manual confirmation.

## Decision Rule

If a quest step can complete without explicit user confirmation, the work is outside Gate 3B and remains blocked by Gate 3C.
