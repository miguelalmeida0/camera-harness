# Gate 3B Perception Claim Language Policy

Gate 3B copy must describe local motion proxy and confirmation-based suggestions. It must not imply autonomous perception, object recognition, production perception, cloud vision, or model/VLM intelligence.

## Allowed Phrases

- camera suggestion;
- local motion proxy;
- motion detected in zone;
- possible writing motion;
- possible typing motion;
- requires confirmation;
- symbolic event;
- local signal.

## Forbidden Phrases

- camera understands your task;
- autonomous vision;
- AI sees what you are doing;
- object recognition proven;
- gesture recognition proven;
- automatic action recognition;
- production perception;
- VLM-powered;
- cloud vision.

## Replacement Rule

- Use `camera suggestion` instead of `recognition`.
- Use `possible writing motion` instead of `writing detected`.
- Use `requires confirmation` instead of `completed automatically`.
- Use `local motion proxy` instead of `AI vision`.

## Failure Rule

Any forbidden phrase in Gate 3B UI, docs, reports, or exported diagnostic artifacts blocks Gate 3B unless it is clearly quarantined as a negative test fixture.
